## 下载说明

> **💡 提示**
> Gitee 附件单文件上限 100 MB，安装包（304.6 MB）以分卷发布。把全部附件下载到**同一个文件夹**，双击 `合并与安装.bat` 即自动拼接并启动安装向导。已安装旧版的用户可直接在「关于」页点「下载并安装更新」，应用内自动完成下载与升级。

| 附件 | 大小 | 说明 |
| --- | --- | --- |
| `setup.exe.001` | 80.0 MB | 安装包分卷 1/4 |
| `setup.exe.002` | 80.0 MB | 安装包分卷 2/4 |
| `setup.exe.003` | 80.0 MB | 安装包分卷 3/4 |
| `setup.exe.004` | 64.6 MB | 安装包分卷 4/4 |
| `合并与安装.bat` | 1 KB | 双击即合并分卷并启动安装向导 |

- Windows 10 / 11：下载上表全部附件到同一文件夹，双击 `合并与安装.bat`
  - 安装向导第二步为「服务端口设置」：默认 18099，被占用或偏好时可改为 1024-65535 任意端口；升级安装自动保留上次的端口选择
  - 装好后想换端口：编辑程序目录下 `port.txt`，重启程序即生效
  - 合并后校验：`SHA256 8fa9adafbda867762df81ca19a43bd2e0a7144b2e11ab2364a3f9893daaee502`
  - 无需管理员权限；Node 与 Chromium 内核已内置，安装即用；杀毒误报时把安装目录加入信任区
  - 首次登录默认账号 `admin`、密码 `admin123`，登录后请在「设置」页立即修改
  - 普通浏览器可访问 `http://127.0.0.1:<你的端口>/`；升级覆盖安装数据不动，卸载保留数据
