## 下载说明

> **💡 提示**
> Gitee 附件单文件上限 100 MB，安装包（304.6 MB）以分卷发布。把全部附件下载到**同一个文件夹**，双击 `合并与安装.bat` 即自动拼接并启动安装向导（向导第二步可设置端口）。

| 附件 | 大小 | 说明 |
| --- | --- | --- |
| `setup.exe.001` | 80.0 MB | 安装包分卷 1/4 |
| `setup.exe.002` | 80.0 MB | 安装包分卷 2/4 |
| `setup.exe.003` | 80.0 MB | 安装包分卷 3/4 |
| `setup.exe.004` | 64.6 MB | 安装包分卷 4/4 |
| `合并与安装.bat` | 1 KB | 双击即合并分卷并启动安装向导 |

- Windows 10 / 11：下载上表全部附件到同一文件夹，双击 `合并与安装.bat`
  - 安装向导第二步为「服务端口设置」：默认 18099，被占用或偏好时可改为 1024-65535 任意端口；升级安装自动保留上次的端口选择
  - 装好后想换端口：编辑程序目录下 `port.txt`，重启程序即生效
  - 合并后校验：`SHA256 8d3551f0569215f686c2004c716af5b37dce1302f0100b8e7fb8a74f66d110fd`
  - 无需管理员权限；Node 与 Chromium 内核已内置，安装即用；杀毒误报时把安装目录加入信任区
  - 首次登录默认账号 `admin`、密码 `admin123`，登录后请在「设置」页立即修改
  - 普通浏览器可访问 `http://127.0.0.1:<你的端口>/`；升级覆盖安装数据不动，卸载保留数据

## 更新说明

**v1.0.2「卧薪尝胆 Update」**

- 托盘驻留：点窗口关闭按钮（✕）时提供两种选择——**最小化到托盘**（窗口隐藏，账号监听与自动回复继续运行）或**退出程序**；托盘图标双击恢复窗口，右键菜单支持「显示鱼小铺 / 退出程序」。挂机跑号从此不必整窗常驻。
- 安装期自定义端口：安装向导新增「服务端口设置」页（默认 18099，实时校验 1024-65535），所选端口落成程序目录的 `port.txt`；静默部署保持默认值，升级安装读回上次端口不重置。运行期端口优先级 `port.txt` > 环境变量 `API_PORT` > 默认。
- 滑块防重复弹出：同一账号的滑块会话加互斥锁（同时只开一个浏览器窗口）；滑块成功后 10 分钟冷却期内的 punish 不再弹窗——服务器风控观察期的滞后信号此前会连环弹窗。
- 滑块快捷测试：设置页「滑块与风控」区新增测试入口（选账号 → 一键取新鲜验证链接 → 当场跑生产同款滑块），通过即真实解除风控并自动更新凭证；账号无风控时直接告知。
