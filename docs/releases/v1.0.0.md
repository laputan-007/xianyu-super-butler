# 🚀 鱼小铺 v1.0.0 —— Windows 桌面客户端正式版

> 闲鱼卖家的多账号一体化运营工作台：账号、商品、订单、消息、AI 回复、自动发货，一个桌面应用全搞定。
> **本版为客户端首个正式发行版：安装即用，零环境依赖。**

## ✨ 本版亮点

- 🖥️ **正规桌面客户端**：单个 `setup.exe` 安装包，双击安装（用户级、**无需管理员权限**），桌面/开始菜单快捷方式一键启动
- 🪟 **无边框原生窗口**：Edge WebView2 内核承载管理后台，自绘标题栏（可拖动移动窗口、最小化/最大化/关闭），窗口关闭即退出
- 📦 **安装即用**：Node 运行时与 Chromium 浏览器内核全部内置，用户机器**不需要安装任何环境**
- 🔄 **卸载保留数据 / 覆盖安装升级**：数据库与账号数据独立于程序文件，升级不丢数据

## ✨ 新功能

- **Windows 客户端**：Inno Setup 用户级安装（支持 `/SILENT` 静默批量部署）、免安装 zip 分发形态并存
- **客户端管理**（关于页「桌面客户端」卡片）：数据存储路径自定义与整体迁移、创建桌面快捷方式、应用内一键重启
- **AI 调用留痕与 token 用量统计**：每次真实 API 调用（含重试）记录 token 用量与回复内容，7 天滚动保留，管理员可查；token 按用户按天聚合进用量统计
- **公告发布系统**：设置页发布公告，SSE 全站实时广播，离线用户登录补推；关于页历史公告列表与删除
- **顶栏通知铃铛**：SSE 共享单例连接，买家新消息 / 系统通知 / 公告三类实时接收，消息直达消息中心
- **宝贝发布所在地三模式**：默认隐私（仅省市）/ 账号定位地址 / 自主选省市区（内置全国 34 省 420 市 4644 区县行政区划数据，隐去精确 POI）
- **智能通知策略**：邮件聚合（满 N 条合并 + 时间窗兜底）、Token 故障熔断（达上限静默、恢复自动重启提醒）
- **主题色换肤**：七种主题色预设即时切换（闲鱼黄/天蓝/水绿/皇家蓝/珊瑚橙/紫罗兰/玫红）+ 浅色/深色/自动外观
- **登录页动效**：漂浮吉祥物贝塞尔航迹巡航、封面鼠标视差、悬停躲闪交互

## 🐛 修复

- Token 故障通知冷却/熔断提升为类级字典，根治实例自愈重启清零导致的「通知轰炸」
- 消息中心进页白屏崩溃（补回丢失的滚动/表情面板绑定）
- Qmsg 渠道校验补 `qmsg→qq` 别名，关于页测试消息不再误报
- 宝贝发布省市区数据模块缺失导致的构建故障（补回 `frontend/data/regions.ts`）
- 账号管理文档截图敏感信息打码（昵称/闲鱼ID/头像/地区）

## ⚡ 优化

- 全站刷新改局部 loading：刷新只更新数据不整页闪烁
- 消息中心 UI 改版：头像两端对齐、气泡圆角、表情面板支持在线图片直发
- 数据概览：内容保留式刷新 + 系统用量三卡紧凑横排
- 版本管理统一：`app/version.py` 单一来源，构建自动打戳（版本/时间/git 提交号）
- 打包一键化：`scripts/build_client.py` 串联前端构建 → PyInstaller → Inno Setup 安装包

## 📦 下载与安装

> Gitee 发行附件单文件上限 100 MB，安装包以**分卷**形式发布（共 4 卷 + 1 个合并脚本，全部下载后运行脚本即自动合并安装）。

1. 下载全部附件放到**同一个文件夹**：`setup.exe.001` ~ `setup.exe.004` 与 `合并与安装.bat`
2. 双击 `合并与安装.bat`——自动拼接出完整 `setup.exe` 并启动安装向导
3. 安装无需管理员权限（默认装到用户目录），完成后从桌面快捷方式启动「鱼小铺」
4. 首次登录：默认账号 `admin` / 默认密码 `admin123`（**登录后请立即在设置页修改**）

**合并后安装包（304.6 MB）SHA256 校验**

```
a26c6e46beb44e1e20a016bb3e88d62ca0cd2293fd01b5aab502a5146ad03769
```

> 分卷同样有校验值，见每卷文件名旁的说明；合并脚本会先校验各卷大小再拼接。

## 🔧 环境要求

- Windows 10 / 11（64 位）
- **零依赖**：Node 与 Chromium 已内置；窗口界面基于 WebView2（Win11 自带，Win10 绝大多数随 Edge 已装）
- 杀毒软件误报时请将安装目录加入信任区

## 🔄 升级与数据

- 升级：直接运行新版本 `setup.exe` 覆盖安装，数据不受影响
- 卸载：控制面板或开始菜单卸载，程序文件清除、**数据目录保留**（重装可继续使用）
- 服务端口默认 `18099`（被占用时可用环境变量 `API_PORT` 覆盖），浏览器亦可直接访问 `http://127.0.0.1:18099/`
