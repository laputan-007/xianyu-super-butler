## 下载说明

> **💡 提示**
> Gitee 附件单文件上限 100 MB，安装包（305 MB）以分卷发布。把全部附件下载到**同一个文件夹**，双击 `合并与安装.bat` 即自动拼接并启动安装向导。

- Windows 10 / 11：下载 `setup.exe.001` ~ `setup.exe.004` 与 `合并与安装.bat`
  - 双击 `合并与安装.bat`，自动拼接出完整安装包（304.6 MB）并启动安装向导；无需管理员权限，默认装到用户目录，桌面自动创建快捷方式
  - 合并后校验：`SHA256 a26c6e46beb44e1e20a016bb3e88d62ca0cd2293fd01b5aab502a5146ad03769`
  - Node 运行时与 Chromium 内核已内置，安装即用；杀毒误报时把安装目录加入信任区即可
  - 首次登录默认账号 `admin`、密码 `admin123`，登录后请在「设置」页立即修改
  - 也支持静默部署：`setup.exe /VERYSILENT /DIR=<路径>`；普通浏览器可访问 `http://127.0.0.1:18099/`
  - 升级直接覆盖安装、数据不动；卸载只清程序文件、保留数据，重装可继续使用

## 更新说明

**v1.0.0「鱼跃龙门 Update」首个正式版**

- 桌面客户端正式亮相：单个 `setup.exe` 安装包完成用户级安装（无需管理员权限）、桌面与开始菜单快捷方式、支持 `/SILENT` 静默批量部署；卸载保留数据，覆盖安装即升级。窗口为无边框原生形态（Edge WebView2 内核），标题栏由界面自绘——可拖动移动窗口，最小化/最大化/关闭一应俱全，窗口关闭即程序退出。浏览器访问网页版时完全不受影响。
- 安装即用：消息签名所需的 Node 运行时直接复用包内 Playwright driver 自带的 node.exe（已实测系统无 Node 时签名链路正常），滑块验证与扫码登录所需的 Chromium 随包分发——用户机器零环境要求。
- 客户端管理：关于页新增「桌面客户端」卡片，数据存储路径可自定义并整体迁移（数据库、日志、账号浏览器配置一并搬家），支持创建桌面快捷方式与应用内一键重启。
- AI 调用留痕与 token 用量统计：每次真实 API 调用（含重试）记录 token 用量与回复内容，7 天滚动保留、管理员可查；token 按用户按天聚合进用量统计，数据概览页柱状图可视化。
- 公告发布系统与顶栏通知铃铛：设置页发布公告全站实时广播（SSE），离线用户登录补推；顶栏铃铛实时接收买家新消息、系统通知与公告，消息直达消息中心。
- 宝贝发布所在地三模式：默认隐私仅显示省市、可跟随账号定位、也可自主选择省市区（内置全国 34 省 420 市 4644 区县行政区划数据），隐去精确 POI 保护卖家隐私。
- 智能通知策略：邮件聚合（满 N 条合并发送 + 时间窗兜底）与异常熔断（连续推送达上限静默、账号恢复自动重启提醒），重要的事第一时间送达，但绝不轰炸。
- 主题外观：浅色/深色/自动外观 + 七种主题色预设即时切换（闲鱼黄/天蓝/水绿/皇家蓝/珊瑚橙/紫罗兰/玫红），经营看板图表色板联动；登录页动效重写为贝塞尔航迹巡航与封面鼠标视差。
- 修复：Token 故障通知冷却/熔断提升为类级字典，根治实例自愈重启清零导致的通知轰炸；消息中心进页白屏；Qmsg 渠道校验 `qmsg→qq` 别名；宝贝发布省市区数据模块缺失导致的构建故障；账号管理文档截图敏感信息打码。
